# Commands

All commands start with `/warcrest`, or the short `/wc`. The old `/imperium` and `/imp` still work.

| Command | What it does |
| --- | --- |
| `/warcrest` | Open or close the addon |
| `/warcrest raids` | Raids tab |
| `/warcrest events` | Events tab: guild events that aren't raids |
| `/warcrest profile` | Edit your profile (spec, when you play, birthday) |
| `/warcrest profiles` | Everyone's profiles, with item levels |
| `/warcrest craft [search]` | The crafters directory: who in the guild can make what |
| `/warcrest recruit` | Recruit tab (officers) |
| `/warcrest dkp` | DKP tab |
| `/warcrest kills` | Kills and Top Head Hunters |
| `/warcrest wanted` | Wanted list |
| `/warcrest card [name]` | A guild member's player card (yours if no name) |
| `/warcrest wishlist` | The guild's loot wishlist, and yours |
| `/warcrest check [name]` | Why achievements have or haven't counted: kills, honor, and what reached the guild |
| `/warcrest bosses` | The last raid bosses that died, and whether each counted for the guild (and why not) |
| `/warcrest achievements` | Your achievements and title |
| `/warcrest addon` | Who has the addon, and who's out of date |
| `/warcrest auction [item] [min bid]` | Auction an item to your raid (officers) |
| `/warcrest council` (or `lc`) | The loot council vote, or start one (officers) |
| `/warcrest calendar` | The Calendar tab: the month's raids, raid nights and events |
| `/warcrest raidrecap` | The last raid night's recap |
| `/warcrest attune` | Who in the guild is attuned for each raid, and has the UBRS and Scholomance keys |
| `/warcrest assign` | Raid assignments: who does what on each boss |
| `/warcrest polls` | Guild polls (the Events tab's Polls view) |
| `/warcrest orders` | Your crafting orders |
| `/warcrest inactive` | Members who haven't logged in lately (officers) |
| `/warcrest test` | Show a test alert (a different kind each time) |
| `/warcrest sound` | Turn alert sounds on or off |
| `/warcrest warn` | Turn on-screen alert banners on or off |
| `/warcrest quiet` | Hold alerts during combat, on or off |
| `/warcrest minimap` | Show or hide the minimap button |
| `/warcrest share` | A short message about Warcrest, to copy and send to a friend or another guild |
| `/warcrest invite` | Invite your guildmates to get Warcrest (officers post it in guild chat) |
| `/warcrest sync` | Catch up on guild history now |
| `/warcrest recap` | Last week's guild recap |
| `/warcrest recap now` | This week's recap so far |
| `/warcrest updates` | What changed in recent versions |
| `/warcrest versions` | Ask guildmates which version they have |
| `/warcrest version` | Your version, plus any problems the addon has hit |
| `/warcrest debug` | Show error details in chat |
| `/warcrest website` | The Warcrest website (guides and a contact form), ready to copy |
| `/warcrest discord` | The Warcrest Discord invite, ready to copy |
| `/warcrest report` | A bug report to copy into the Discord or the contact form |
| `/warcrest setup` | Set Warcrest up for your guild: who manages it, DKP and the guild's alerts (officers) |
